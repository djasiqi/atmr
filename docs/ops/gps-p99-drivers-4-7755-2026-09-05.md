## Lecture métier

- **Carte « live »** : aux heures saines, p50 4 = 1,7 s (excellent). Aux heures tardives, **chaque** point affiché a déjà 1–2 min d’âge à l’acceptation — ce n’est pas un outlier.
- Ce n’est **pas** le pipeline. Ne pas toucher Redis / Kafka / fanout / fréquences backend pour ça.
- La cadence **1 Hz** en LIVE HTTP est déjà hors contrat produit (~8 s). Elle peut expliquer à elle seule une pression 429 si retries ou double producteur (clé limiter à vérifier **après**, sans monter les seuils).
- DRIVER-3 Android sur la même app **1.0.13** a un p99 de 57 s : le problème est **iOS / file / cadence**, pas le contrat GPS serveur.
